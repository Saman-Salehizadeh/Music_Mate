# Music-Mate
Music-Mate is a python library that gets your voice or video and gives you its notes in a PDF.
To install it, run this prompt on terminal:
```bash
pip install git+https://github.com/Saman-Salehizadeh/Music_Mate.git
```
You can use this library as you see:
```python
import music_mate
music_mate.media_to_notes(input_path,output_path)
```
The accurancy is not very good in this version and it's suitable with basic instruments, but in the future versions it will have functions for piano, guitar, etc.
